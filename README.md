# Battle of the Birth Months

The December Group's gospel karaoke fundraiser — a birth-month showdown with solo and group/choir acts, three rounds, and dollar-vote audience judging.

**Live site:** https://impactops-bgi.github.io/december-group-karaoke/

The site includes event details, entry fees, voting rules, the official 50-song playlist, a live tally board for show night, and printable registration sheets.
